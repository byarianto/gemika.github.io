# Privacy Policy — WhatsApp Seller Copilot

**Effective Date:** November 14, 2026

WhatsApp Seller Copilot ("the Extension") is a **free** Chrome browser extension designed to help sellers and admins record and manage customer orders directly from WhatsApp Web (`https://web.whatsapp.com/`).

## 1. Data Processed
The Extension only reads active chat content on WhatsApp Web **strictly upon explicit user action** (when you click *Ambil dari WA* or *Sisipkan*), and stores the following data locally in your browser (`chrome.storage.local`):
- Temporary order drafts per contact, product catalog items, quick-reply (FAQ) templates, store sender identity, and buyer notes/status tags.
- Optional user-supplied settings, specifically your own Google Apps Script Web App URL and/or your own Gemini API Key.

## 2. Data Sharing & Third-Party Services
- **The developer operates no backend server** and never collects, stores, sells, or accesses your personal data, order records, or WhatsApp conversations.
- If you connect **Google Sheets**, order records, products, customer notes, and FAQ templates are sent directly from your browser to **your own Google Apps Script Web App** (`script.google.com`).
- If you enter **your own Gemini API Key** and click *Isi Otomatis*, only the selected chat text is sent directly to the Google Gemini API (`generativelanguage.googleapis.com`) using your own API key.

## 3. Data Security & User Control
All local data remains in your browser's `chrome.storage.local`. You have full control to clear or delete all stored data at any time through Chrome's extension settings or by uninstalling the Extension.

## 4. Contact
If you have any questions regarding this Privacy Policy, please reach out through the developer contact / Support tab on the Chrome Web Store listing page for WhatsApp Seller Copilot.
